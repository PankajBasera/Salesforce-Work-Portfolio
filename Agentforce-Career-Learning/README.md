# Agentforce Career Learning Kit

Senior Salesforce Developer path: **Agentblazer Champion → Innovator → Legend 2026** plus **Salesforce Certified Agentforce Specialist**, with portfolio projects and resume artifacts.

**Daily cadence:** 1–2 hours (45–60 min Trailhead/docs + 30–45 min hands-on in org).

## Quick start

1. Open [Agentblazer hub](https://trailhead.salesforce.com/agentblazer) and start **Champion 2026**.
2. Follow [00-schedule/daily-tracker.md](00-schedule/daily-tracker.md) each day.
3. Work phase folders in order (`01` → `05`).
4. After each phase, copy the resume line into [05-cert-and-resume/resume-linkedin.md](05-cert-and-resume/resume-linkedin.md).
5. Track overall status in [PROGRESS.md](PROGRESS.md).
