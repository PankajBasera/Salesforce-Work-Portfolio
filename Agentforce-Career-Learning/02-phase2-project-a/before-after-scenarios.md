# Project A — Five Before/After Scenarios (interview gold)

Fill metrics with estimates from your org, or use qualitative time language until you measure.

## 1. Long email-to-case thread

| | |
| --- | --- |
| **Before** | Rep reads 20+ emails (~8–12 min) before first meaningful action |
| **After** | Agent summary in ~30–60 sec; rep verifies and acts |
| **Time saved** | |
| **Risk / control** | Human verifies before customer send |

## 2. Related history hunting

| | |
| --- | --- |
| **Before** | Manual clicks across Cases, Assets, Entitlements |
| **After** | Get Context action returns structured related facts |
| **Time saved** | |
| **Risk / control** | Read-only action; no silent writes |

## 3. First reply drafting

| | |
| --- | --- |
| **Before** | Blank email; inconsistent tone/policy language |
| **After** | Suggested reply draft with no-commitment rules |
| **Time saved** | |
| **Risk / control** | Draft only; human sends |

## 4. Triage notes consistency

| | |
| --- | --- |
| **Before** | Notes missing or free-form; handoffs suffer |
| **After** | Update Triage Fields writes structured notes |
| **Time saved** | |
| **Risk / control** | Field whitelist |

## 5. Unsafe customer request (refund)

| | |
| --- | --- |
| **Before** | Junior rep may over-promise in chat |
| **After** | Agent refuses + creates Task for policy owner |
| **Time saved** | (quality / risk reduction, not speed) |
| **Risk / control** | Instruction + action design prevents write of credit |

## Interview line

> “I didn’t replace the agent with AI — I removed the slow, repetitive parts of triage and kept humans on decisions that carry customer and compliance risk.”
